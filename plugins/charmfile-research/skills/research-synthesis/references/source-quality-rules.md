# Source Quality Rules

Prefer sources in this order:

1. Official documentation or standards.
2. Primary GitHub repositories and release notes.
3. Maintainer blogs or engineering posts.
4. Reputable third-party technical writeups.
5. Community posts only as supporting context.

For OpenAI/Codex questions, use official OpenAI docs or the Codex manual first.

For technical implementation details, prefer primary sources over SEO articles.

When sources conflict, say so and prefer the more authoritative or newer source.
