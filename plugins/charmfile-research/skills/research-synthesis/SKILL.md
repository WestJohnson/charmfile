# Research Synthesis

Use this workflow for source-backed research.

## Workflow

1. Clarify the decision or question being researched.
2. Use primary sources first: official docs, specs, repo READMEs, release notes, source code, or papers.
3. Prefer recent sources when the topic changes quickly.
4. Compare at least two independent source families when possible.
5. Separate facts, inferences, and recommendations.
6. Record links to sources used.
7. Produce a practical recommendation and next step.

## Reference

- Read `references/source-quality-rules.md` before broad research.

## Output Shape

Return:

- short answer
- source-backed findings
- tradeoffs
- recommendation
- links used
