# Mobile UI Checklist

Check at minimum:

1. Mobile navigation opens, closes, and does not overlap content.
2. Buttons and links are tappable.
3. Text fits containers without clipping or overlap.
4. Hero and first viewport show the actual product, place, service, or offer.
5. Forms are usable on mobile.
6. Sticky headers, modals, and menus do not block key actions.
7. Images load and are not dark, blurred, or purely decorative when inspection matters.
8. Important conversion actions remain visible and reachable.

Use screenshots or browser inspection when possible. Do not rely only on code reading for visual quality.
